# Project Documentation

## Project Overview
This project demonstrates the integration between Jira and GitHub for managing software development tasks.

## Objectives
- Manage project tasks using Jira.
- Link Jira work items with GitHub development activities.
- Create dedicated GitHub branches for Jira tasks.
- Track commits and pull requests from Jira.
- Maintain clear project documentation.

## Jira and GitHub Integration
Jira is connected with the GitHub repository to provide traceability between project management and source code development.

Each development task can be associated with:
- A Jira work item
- A GitHub branch
- Commits
- Pull requests

## Workflow
1. Create a work item in Jira.
2. Create a GitHub branch from the Jira work item.
3. Implement the required changes.
4. Commit the changes to the branch.
5. Create a pull request.
6. Review and merge the pull request.
